## Overview

BFD3 is a professional acoustic drum sampler captured in high-definition with 100+ multi-velocity layers, cymbal and hi-hat round-robin, bleed between channels, and an on-board mixer with 100+ effects.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **BFD Drums** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multi-Velocity Layers** | Up to 128 velocity layers per articulation for realistic expression |
| **Bleed Channels** | Configurable bleed from each drum into neighboring microphone channels |
| **Hi-Hat Physics** | Continuous pedal-position control for authentic open-to-closed range |
| **On-Board Mixer** | 32-channel mixer with send effects and drum room simulation |
